# Phase 15C — Sequence-only versus reference-structure Forest

**Hypothesis:** Experimentally grounded, position-indexed CFTR reference structural features may add out-of-fold predictive information about *in-vitro* VTI rescue beyond the original 68 amino-acid sequence features.

**Data:** Frozen 2026 VTI **training only** (210 variants / 168 protein positions; 66 previously ETI-characterised and 144 VTI-only). Experimental labels are read only for keys in this training split. Neither study's validation/test outcome table is read. No split is regenerated. ETI labels are not needed.

**Structural sources:** Reference cryo-EM CFTR structures 6O2P and 8EIQ; 8EIQ is an F508del construct; the biological assay is M470 and the canonical structure reference generally V470. Distances are reference Cα-to-observed-heavy-ligand-atom distances, **not mutant ligand affinities**. There is no observed vanzacaftor pose in these two structures. Protein-only solvent exposure ignores the lipid membrane.

**Predefined features (12):** reference Cα contact count, >100-residue sequence-separated contact count, protein SASA, relative SASA; 6O2P VX7 Cα distance; 8EIQ VX7/CV6/WJX Cα distances; resolved-position indicators (overall, 6O2P, 8EIQ); M470 assay background mismatch flag. Feature values remain missing for unresolved residues, then are median-imputed within each training fold only. No variants are removed for missing structural features. The study cohort/response grouping is not a predictive feature.

**Models:** The originally frozen VTI-only Random Forest (250 trees, min leaf size 4, max_features=0.75, seed per fold) is compared with the **same** estimator on original 68 features plus the 12 structural features. A negative-control model receives position-wise shuffled structural vectors with the same number of dimensions. The baseline Forest is re-fitted in each fold and *must* reproduce the saved out-of-fold predictions exactly (1e-6 tolerance), or execution stops.

**CV:** Reuse the stored original 2 × 5 folds, grouped by protein position. For each held-out position, all variants at that position are excluded from training. The two predictions per variant are averaged *before* scoring. The primary endpoint is equal-position mean absolute error on raw `vti_rescue_pp`. Report signed bias and position-clustered paired bootstrap 95% CIs vs original Forest and shuffled-structure control; report both retrospectively defined cohorts separately.

**Secondary endpoint:** The existing raw VTI rescue ≥10 pp classification, with fixed threshold applied to the regression outputs, assessed using position-weighted balanced accuracy, sensitivity/specificity, AUROC, non-responder average precision and counts of correctly identified non-responders. This does **not** reproduce the original publication's empirical-Bayes classifications; continuous predictions are not calibrated probabilities. No threshold fitting.

**Interpretation:** Genuine structural benefit would require overall improvement beyond both Forest and shuffled-structure controls, without an unacceptable worst-cohort penalty. A small exploratory training-CV improvement is not external validation or proof of modulator binding. Static structural features are shared among substitutions at the same residue and cannot describe mutation-specific ΔΔG, folding, trafficking, gating or drug affinity. If performance fails to improve, do not try a large model sweep; review feature biology and confirm assay-grounded structures before Boltz/AlphaFold pilots.

**Outputs:** `results/structure/phase15c_train_oof.csv`, `phase15c_summary.csv`, `phase15c_summary.json`, with raw-data/feature/protocol SHA-256 provenance. All results remain exploratory training-only data. The final 108 ETI and 33 VTI test variants stay sealed.
